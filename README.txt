IMPORTANT BEFORE PUBLICATION:
1. Replace hello@curiosphere.example with a real email address.
2. Add real editorial sources and fact-check each article before publishing.
3. Review and expand the privacy notice once analytics, ads, cookies or forms are added.
4. Check the CurioSphere name and domain/trademark availability before investing in branding.
5. The current website is a static starter; it has no CMS, hosting, custom domain, analytics or ad integration.

FREE PUBLISHING OPTION:
Use GitHub Pages:
1. Create/sign in to a GitHub account.
2. Create a public repository named curiosphere.
3. Upload all files and folders from this package (keep the folder structure).
4. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
5. GitHub will provide a public github.io address after deployment.

A free GitHub Pages address is not a custom domain. Hosting availability and terms are controlled by GitHub.
